# Vibe code lab

Web projects built with AI tools by [Dr. Wes Fryer](https://www.wesfryer.com/), shared so students and teachers can open them, compare them, and remix them.

Live site: https://wfryer.github.io/vibe-code-lab/

## Projects

### Copyright game peer review results

Four AI tools were each asked to turn our class's copyright game peer review results into a website. [Open the project page](https://wfryer.github.io/vibe-code-lab/copyright-peer-review-results/) to see all four together.

- [Gemini (3.6 Thinking)](https://wfryer.github.io/vibe-code-lab/copyright-peer-review-results/gemini-visualization.html)
- [ChatGPT](https://wfryer.github.io/vibe-code-lab/copyright-peer-review-results/chatgpt-visualization%20%281%29.html)
- [Claude (Opus 5.5 High)](https://wfryer.github.io/vibe-code-lab/copyright-peer-review-results/claude-opus-visualization%20%281%29.html)
- [Canva AI](https://providenceday.my.canva.site/copyright-game-peer-review-results) (opens on Canva, because the raw HTML needs files Canva hosts)

[Full documentation of this project](https://docs.google.com/document/d/1NrVBo4o9FFcLz_GgXTgTifrn9Cw2QPyiJx_r1Omr0mI/edit?usp=sharing)

## How to add a new project

1. Make a new folder with a short, lowercase name.
2. Put the HTML file or files inside it.
3. Add a link to the new folder in `index.html` and in this README.
