# Vibe code lab

Web projects built with AI tools by [Dr. Wes Fryer](https://www.wesfryer.com/), shared so students and teachers can open them, compare them, and remix them.

Live site: https://wfryer.github.io/vibe-code-lab/

## Projects

### Copyright game peer review results

Four AI tools were each asked to turn our class's copyright game peer review results into a website.

- [Gemini (3.6 Thinking)](https://wfryer.github.io/vibe-code-lab/copyright-peer-review-results/gemini.html)
- [ChatGPT](https://wfryer.github.io/vibe-code-lab/copyright-peer-review-results/chatgpt.html)
- [Claude (Opus 5.5 High)](https://wfryer.github.io/vibe-code-lab/copyright-peer-review-results/claude.html)
- [Canva AI](https://providenceday.my.canva.site/copyright-game-peer-review-results) (opens on Canva, because the raw HTML needs files Canva hosts)

[Full documentation of this project](https://docs.google.com/document/d/1DQQfB3-aRiPqmwsZu2HZzwBJe0yb_Y1p4V_-9qCCNF8/edit?usp=sharing)

## How to add a new project

1. Make a new folder with a short, lowercase name.
2. Put the HTML file or files inside it.
3. Add a link to the new folder in `index.html` and in this README.
